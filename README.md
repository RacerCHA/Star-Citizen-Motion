# Star Citizen Motion

**Star Citizen → SimHub Motion и MOZA Cockpit, с приложением в трее Windows.** Один канал D-BOX LiveMotion питает два независимо включаемых выхода. Для проверки на исходном ПК физический контроллер D-BOX не использовался.

**v0.2.0** добавляет MOZA через локальный DCS-совместимый TCP-сервер и отдельный пресет AB9. SimHub зарегистрирован как **Flight** и продолжает получать исходные ускорения без фильтров. Для MOZA меняются оси/единицы и масштаб скорости; пики ускорения не обрезаются. Программные проверки пройдены; пользователь подтвердил работу FFB в живом полёте. Отдельная версия пресета **v0.3 Soft** уменьшает Stick Shaker и направленные усилия; её ощущения ещё не проверены. Рабочая версия только для SimHub сохранена тегом **v0.1.0**.

## Установка с нуля

### 1. Установить зависимости

| Компонент | Что нужно |
|---|---|
| Windows | Windows 10/11 x64 с .NET Framework 4.x; исходная проверка выполнена на Windows 11 |
| Star Citizen | Установленная игра; проверенная сборка LIVE 4.10.2 / 12913470 |
| [SimHub](https://www.simhubdash.com/download-2/) | Проверено на 9.13.3. External Sim появился в 9.11.5; более старые версии не подходят. Для управления платформой нужна подходящая лицензия Motion |
| [Node.js](https://nodejs.org/en/download) | Актуальная LTS-версия, стандартная установка Windows. npm-пакеты не нужны |
| [PowerShell 7](https://github.com/PowerShell/PowerShell/releases/latest) | Нужен для создания локального сертификата; `pwsh.exe` должен быть доступен через PATH |
| D-BOX HaptiSync Center | **Именно 1.4.0**, проверенный коннектор `2.0.0.20040`. [Установщик на сайте D-BOX](https://www.d-box.com/hubfs/Software-Downloads/HSC_Releases/HSC_1.4.0_setup.exe) |

Установщик этого проекта проверяет хеш и цифровую подпись коннектора. Совместимость с другими версиями HSC не заявлена. При несовпадении он остановится; отключать проверку не нужно. DLL D-BOX и его установщик не входят в проект.

### 2. Распаковать приложение

Скачай готовый архив нужной версии из Releases и распакуй целиком в постоянную доступную для записи папку, например `C:\Tools\StarCitizen-Motion`. Запускай приложение из распакованной папки, а не внутри ZIP. Если новая версия пока находится в ветке разработки, скачай её исходники и запусти `Build.cmd`.

В готовом архиве уже есть `StarCitizenTelemetry.exe` и `settings.json`. При скачивании исходников через **Code → Download ZIP** сначала запусти `Build.cmd`: он соберёт EXE и создаст настройки из `settings.example.json`.

Если Node.js или SimHub установлены в нестандартное место, исправь `NodePath` или `SimHubPath` в `settings.json`. Путь к сертификату по умолчанию — `runtime\cert` внутри папки приложения.

### 3. Создать сертификат этого компьютера

Закрой Star Citizen и предыдущие экземпляры моста. Окно HaptiSync Center тоже можно закрыть; службы Windows менять не требуется.

Запусти `Prepare-Certificate.cmd` от своего обычного пользователя. Он создаст `runtime\cert\lm.crt` и `runtime\cert\lm.key`. Windows-хранилище доверенных сертификатов не меняется. Готовая пара не перезаписывается.

Сертификат действует один год. Не передавай приватный `lm.key` другим пользователям: на каждом ПК создаётся собственная пара.

### 4. Настроить локальный канал D-BOX

Запусти **`Setup-DBox.cmd` от имени администратора**, используя тот же аккаунт Windows. Игра должна быть закрыта.

Скрипт использует установленный, подписанный коннектор D-BOX и выполняет только следующие действия:

- Копирует коннектор и конфигурацию из `C:\ProgramData\D-BOX\Gaming\LiveMotion\LiveMotionConnector` в соседнюю папку `StarCitizen`.
- Устанавливает публичный сертификат локального приёмника в `livemotion.crt` этих двух папок.
- Сохраняет исходный сертификат и журнал изменений в `runtime` приложения для отката.

Дождись сообщения **`INSTALLED AND VERIFIED`**. Скрипт не изменяет игру, античит, брандмауэр, службы или Windows root store. Это неофициальная интеграция; отдельного одобрения CIG или гарантий совместимости с будущими патчами нет.

### 5. Добавить Star Citizen в SimHub

1. В SimHub открой **Настройки → Общее / Global** и включи инструменты разработки определений телеметрии — **game definition authoring tools**.
2. Открой появившийся **Game Definition Editor**.
3. Через **File → Open** открой `StarCitizen.simdef` из папки приложения.
4. На вкладке **Definition registration** нажми **Register definition**.
5. В **Global behaviour** проверь **Game family: Flight**. Файл уже содержит это значение.
6. Закрой редактор и выбери **Star Citizen** в списке симуляторов SimHub. Если список не обновился, перезапусти SimHub.

Определение ссылается на своё расположение. После переноса папки зарегистрируй его заново. Не меняй GUID, сигнатуры и порядок полей: они должны совпадать с отправителем.

### 6. Запустить полёт

1. Открой **`StarCitizenTelemetry.exe`**. В трее появится синяя молния, приёмник и мост запустятся автоматически.
2. Оставь **SimHub запущенным**.
3. Запускай игру **обычным способом через RSI Launcher**, после приложения. Специальные параметры запуска не нужны.
4. Сядь в пилотское кресло корабля. Двойной щелчок по молнии открывает состояние: ожидается **«Телеметрия корабля поступает»**, растущий счётчик, частота и XYZ.
5. Проверь направления в SimHub и используй собственные настройки платформы. Приложение не включает движение платформы автоматически.

В окне и меню молнии есть отдельные переключатели **SimHub** и **MOZA**. При запуске SimHub включён, MOZA выключена. Выключение одного выхода сохраняет общий приёмник, чтобы не терять подключение игры. **Остановить всё** выключает оба выхода и приёмник. Крестик скрывает окно в трей; **Выход** завершает приложение и его дочерние процессы.

### 7. Подключить MOZA AB9

1. Открой MOZA Cockpit. Проверенная версия интерфейса: 1.1.5.42.
2. В Local Preset нажми **Import**, выбери `presets\StarCitizen-AB9-v0.3-Soft.preset`, затем **Import → Load Now**. Игра — DCS World, самолёт — A-10C II, режим — Telemetry FFB. Пресет Elite остаётся отдельным.
3. DCS-канал Cockpit должен подключаться к `127.0.0.1:3476`. Если у тебя другой порт экспорта DCS, укажи его в `MozaTcpPort` файла `settings.json`. Стандартный экспорт MOZA может использовать 1234; на исходном ПК настроен 3476. Инструкция настройки и ограничения — [MOZA](docs/moza.md).
4. Закрой мост Elite/настоящий DCS, если запущен. В молнии нажми **MOZA: ВЫКЛ — включить**. Приложение само запускает свой `DCS.exe` и закрывает его при выключении MOZA.
5. В кресле пилота проверь **«MOZA подключена»** и растущий счётчик TCP. Выбери пресет Star Citizen вручную, если Cockpit загрузил другой: оба моста представляются A-10C II.

Все реализованные эффекты работают одновременно. Настройки силы остаются в Cockpit; захват не пишет полный полёт на диск. На пешем участке или при устаревании данных MOZA получает `export_stop`.

## Если данных нет

| Симптом | Проверка |
|---|---|
| Ожидание игры, счётчик не растёт | Запусти приложение перед игрой. После остановки/перезапуска приёмника во время полёта может потребоваться перезапуск самой игры |
| Ошибка занятого порта | Закрой прежний приёмник, `Start-Capture` и `udp-record`. Они не должны одновременно занимать порты 61666/56061 |
| Нет Star Citizen в SimHub | Проверь регистрацию `.simdef` и версию SimHub. Семейство — Flight |
| Приложение видит поток, SimHub — нет | Выбери Star Citizen, проверь UDP 56062, неизменность `.simdef` и журнал SimHub |
| Не найден Node.js/сертификат | Проверь пути в `settings.json` и завершение шага создания сертификата |
| Setup сообщает другую подпись/хеш | Нужен проверенный HSC 1.4.0. Скрипт намеренно не заменяет неизвестные версии |

Диагностика: `runtime\app.log`, `runtime\app-status.json`, `runtime\status.json` и `runtime\receiver\latest-status.json`. Обычный запуск **не записывает полные потоки** на диск. Сеанс ограничен 24 часами, после чего мост нужно запустить снова.

## Откат

Закрой игру и приложение. Запусти **`Rollback-DBox.cmd` от имени администратора** из той же папки. Он восстановит сохранённый сертификат и удалит только созданные им файлы, если они не изменялись после установки. При внешних изменениях остановится, сохранив их. Папку `runtime` нельзя удалять до отката.

Для обновления истёкшего сертификата сначала выполни откат, затем сохрани старую пару отдельно, создай новую и повтори Setup. При необходимости удали регистрацию определения через SimHub.

## Данные и проверенный результат

Ускорения поступают из **одного канала Star Citizen → D-BOX**. Приёмник отдаёт JSON на `127.0.0.1:56061`, мост — двоичный пакет SimHub на `127.0.0.1:56062`. Вход приёмника — TLS/gRPC `127.0.0.1:61666`. Трафик остаётся на локальном компьютере.

В исходной проверке захвачено **18 390 кадров**, в среднем **65.8 Гц**. Все три компоненты ускорения сохранены в пакетах без изменения значений. SimHub подтвердил корректный приём; автор проверил работу интеграции. Это результат конкретной конфигурации, а не гарантия для всех сборок игры и платформ.

Подробности: [поля и ограничения](docs/telemetry.md), [проверки и сборка](docs/development.md), [история версий](CHANGELOG.md).
